## 2024-10-27 - React useMemo array filtering bottleneck
**Learning:** Code in `frontend/src/components/PolicyIntelPlatform.tsx` revealed an anti-pattern where a large `bills` array was filtered synchronously inside the functional component body via `const filteredBills = bills.filter(...)`. Since this component tracks several state variables like `activeViewMode`, `isLoadingMemo`, and `selectedBill`, every state update caused the `O(N)` list filtering to re-run needlessly, blocking the main thread and slowing down UI responsiveness when switching between tabs.
**Action:** In large data-heavy views displaying lists, always wrap list filter, map, or reduce computations in `React.useMemo` if they iterate over large arrays and are only dependent on specific filters. This isolates the computation from unrelated state changes in the component.
