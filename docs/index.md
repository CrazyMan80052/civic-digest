# CivicDigest Documentation

Welcome to the CivicDigest documentation! CivicDigest is a platform comprised of a Next.js frontend and a FastAPI backend designed to provide a municipal transparency service.

## Project Structure

The project is structured into two main components:

- **Frontend:** A Next.js App Router application in the `frontend/` directory.
- **Backend:** A Python FastAPI scraping and analytics microservice in the `backend/` directory.

Use the navigation to learn more about each component.
